# 현관 도어 트리거 테스트 (ESP32 BLE 마우스)

폰(갤럭시 S24)이 멀어졌다가 현관으로 다가올 때 **재연결까지 걸리는 시간**을 측정하는 1단계 테스트.
이 시간이 충분히 짧아야 "문 앞에 오면 자동 문열림"으로 쓸 수 있다.

## 올리는 법 (둘 중 하나)

### A. PlatformIO (추천 — 라이브러리 자동 설치)
1. VS Code + PlatformIO 확장 설치
2. 이 폴더(`door-mouse-test`)를 PlatformIO로 열기
3. ESP32를 USB로 연결
4. 아래쪽 ✔(Build) → →(Upload) 클릭 (라이브러리는 자동 다운로드됨)
5. 🔌(Serial Monitor) 클릭, 속도 115200

### B. Arduino IDE
1. Boards Manager에서 "esp32"(Espressif) 설치
2. 라이브러리: https://github.com/T-vK/ESP32-BLE-Mouse → Code → Download ZIP
   → Arduino IDE: 스케치 → 라이브러리 포함 → .ZIP 라이브러리 추가
3. `src/main.cpp` 내용을 새 스케치에 붙여넣기
4. 보드: "ESP32 Dev Module", 포트 선택 → 업로드
5. 시리얼 모니터 115200

## 테스트 순서
1. 폰 블루투스에서 **'Door Mouse'** 페어링 (한 번)
   - 목록에 안 뜨면: 설정 → 개발자 옵션 → "지원되지 않는 BLE 기기 표시" 켜기
2. `[최초 연결됨]` 확인 → 폰 들고 **집 밖/먼 방**으로 이동 → `[끊김]` 확인
3. 폰 **화면 끄고 주머니에 1~2분** (절전 진입) → **현관으로 다가오기**
4. `[재연결] 걸린 시간` 기록 → **여러 번 반복**

## 판정
- **2~3초 이내로 꾸준** → 문 트리거로 쓸만함 → 2단계(HA 연동)로
- **10초 이상 / 들쭉날쭉** → 문 트리거엔 무리 → 집/외출 신호로만

## 안 되는 경우
- 'Door Mouse'가 아예 목록에 안 뜸 / 페어링 실패 → 알려주세요. NimBLE + 명시적 본딩 방식으로 바꿉니다.
- `[끊김]` 후 아무리 다가와도 `[재연결]`이 안 뜸 → 안드로이드가 자동 재연결을 안 하는 것. 역시 방식 변경 필요.
